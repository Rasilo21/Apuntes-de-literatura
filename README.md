# Quiz: Literatura medieval española

Quiz interactivo creado con HTML, CSS y JavaScript a partir de los apuntes proporcionados.

## Cómo usarlo
1. Descarga los tres archivos.
2. Mantén `index.html`, `style.css` y `script.js` en la misma carpeta.
3. Abre `index.html` en un navegador.

## Publicarlo con GitHub Pages
1. Sube los tres archivos a un repositorio de GitHub.
2. Entra en Settings → Pages.
3. En Build and deployment, selecciona Deploy from a branch.
4. Selecciona la rama `main` y la carpeta `/ (root)`, y guarda.
5. GitHub te dará un enlace público para compartir el quiz.
